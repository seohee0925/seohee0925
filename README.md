## 📚 Research & Publications

### COMPEL: Compensated Mixture-of-Experts Pruning with Expert-Layer Distribution

**First Author · Findings of ACL 2026**

[![ACL 2026](https://img.shields.io/badge/ACL%202026-Findings-1f6feb?style=flat-square)](https://aclanthology.org/2026.findings-acl.1521/)
[![Paper](https://img.shields.io/badge/Paper-ACL%20Anthology-b31b1b?style=flat-square)](https://aclanthology.org/2026.findings-acl.1521.pdf)

A layer-adaptive expert pruning framework for reducing the inference cost of
Mixture-of-Experts models while preserving model performance.

* Performs layer-adaptive expert pruning based on **Expert-Layer Distribution**
* Compensates for information loss after expert pruning
* **25% expert pruning** on Qwen1.5-MoE
* GPU Memory: **9.48 GB → 7.78 GB**
* Throughput: **45.21 → 69.42 tokens/s**
* Average Performance: **68.37 → 68.34**
* At 50% pruning, compensation improves PPL from **8.97 → 8.03**

### CLAWS: Creativity Detection for LLM-generated Solutions using Attention Window of Sections

**NeurIPS 2025 · Main Conference**

[![NeurIPS 2025](https://img.shields.io/badge/NeurIPS%202025-Main%20Conference-8A2BE2?style=flat-square)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/c173f0a085728061bcd5b8a419170199-Abstract-Conference.html)
[![Paper](https://img.shields.io/badge/Paper-NeurIPS-b31b1b?style=flat-square)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/c173f0a085728061bcd5b8a419170199-Abstract-Conference.html)
[![Code](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square\&logo=github)](https://github.com/kkt94/CLAWS)

A white-box method for distinguishing **Typical, Creative, and Hallucinated**
solutions generated by reasoning LLMs.

* Analyzes attention patterns across semantic sections of prompts and responses
* Uses section-wise attention features to characterize generation behavior
* Distinguishes creative reasoning from hallucinated responses
* Evaluated across multiple reasoning LLMs and mathematical reasoning problems

### ICB-CG: In-Context Bandit for Code Generation

**ACL Rolling Review 2026**

A training-free framework that improves code generation by accumulating
and selectively reusing execution feedback during inference.

* Converts execution feedback into reusable in-context experiences
* Selects useful experiences through an **In-Context Bandit**
* Improves generation without additional parameter updates
* Evaluated on **HumanEval+, MBPP+, and LiveCodeBench**

---

### DOSSIER

**Long-Context Multi-Document Question Answering**

A document-organized retrieval and synthesis framework for improving
evidence retrieval over long and multi-document contexts.

* Normalizes evidence from heterogeneous documents into a common structure
* Organizes long documents while preserving structural information
* Retrieves question-relevant evidence instead of relying on full-context processing
* Generates answers based on explicitly selected and source-grounded evidence
