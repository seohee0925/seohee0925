### COMPEL: Compensated Mixture-of-Experts Pruning with Expert-Layer Distribution

**First Author · Findings of ACL 2026**

[![ACL 2026](https://img.shields.io/badge/ACL%202026-Findings-1f6feb?style=flat-square)](https://aclanthology.org/2026.findings-acl.1521/)
[![Paper](https://img.shields.io/badge/Paper-ACL%20Anthology-b31b1b?style=flat-square)](https://aclanthology.org/2026.findings-acl.1521.pdf)

A layer-adaptive expert pruning framework for reducing the inference cost of
Mixture-of-Experts models while preserving model performance.

- Estimates expert importance using **Fisher Information**
- Performs layer-adaptive pruning based on **Expert-Layer Distribution**
- Compensates pruned experts through Fisher-guided weight compensation
- **25% expert pruning** on Qwen1.5-MoE-A2.7B
- GPU Memory: **9.48 GB → 7.78 GB**
- Throughput: **45.21 → 69.42 tokens/s**
- Average Performance: **68.37 → 68.34**
- Reduced performance degradation even under **50% expert pruning**

### CLAWS: Creativity Detection for LLM-generated Solutions using Attention Window of Sections

**NeurIPS 2025 · Main Conference**

[![NeurIPS 2025](https://img.shields.io/badge/NeurIPS%202025-Main%20Conference-8A2BE2?style=flat-square)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/c173f0a085728061bcd5b8a419170199-Abstract-Conference.html)
[![Paper](https://img.shields.io/badge/Paper-NeurIPS-b31b1b?style=flat-square)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/c173f0a085728061bcd5b8a419170199-Abstract-Conference.html)
[![Code](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/kkt94/CLAWS)

A white-box method for distinguishing **Typical, Creative, and Hallucinated**
solutions generated by reasoning LLMs without requiring human evaluation.

- Divides prompts and responses into semantic sections and analyzes their attention distributions
- Uses section-wise attention ratios as features for generation classification
- Evaluated on **5 reasoning LLMs** and **4,545 mathematical problems**
- Outperformed five existing white-box detection methods across
  **F1, AUROC, and AP-based evaluation metrics**

### ICB-CG: In-Context Bandit for Code Generation

**ACL Rolling Review 2026 · Under Review**

A training-free code generation framework that improves subsequent generations
by accumulating and selectively reusing execution feedback during inference.

- Converts code execution results into reusable in-context experiences
- Updates experience-selection probabilities through an **In-Context Bandit**
- Improves generation without parameter updates or additional model training
- Evaluated with **Qwen3.5-9B** and **DeepSeek-Coder-6.7B-Instruct**
- Experiments on **HumanEval+, MBPP+, and LiveCodeBench**

### DOSSIER

**Long-Context Multi-Document Question Answering · Under Review**

A document-organized search and synthesis framework designed to improve
evidence retrieval and reasoning over long, multi-document contexts.

- Organizes documents using hierarchical structures before retrieval
- Selects only question-relevant sections instead of processing full documents
- Structures retrieved evidence using **5W1H-based evidence records**
- Generates answers grounded in explicitly selected source evidence
- Evaluated on long-context multi-document QA benchmarks including **Loong**
